# Standarisasi Coding — Tugas Pengujian & Integrasi

## 📋 Deskripsi

Project latihan penerapan standar pengujian (AAA, FIRST) dan integrasi kode (GitHub Actions CI) pada modul ShoppingCart dan User.

## 🛠️ Teknologi

- Node.js v20
- Jest (testing)
- ESLint (linting)
- Prettier (formatting)
- GitHub Actions (CI)

## 🚀 Cara Menjalankan

```bash
npm install
npm test
npm run test:coverage
npm run lint
npm run format:check
```
